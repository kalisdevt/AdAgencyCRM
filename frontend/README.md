# CRM-Агентство — клиентская часть

Веб-интерфейс CRM рекламного агентства: Vue 3 (Composition API), Vite, vue-router.

Экраны: вход, лента «Входящие» с панелью диалога, карточка клиента, управление пользователями (администратор) и демонстрационная форма заявки сайта (`/request`).

```sh
npm install
npm run dev      # http://localhost:5173, запросы /api проксируются на localhost:3000
npm run build    # production-сборка в dist/
```

Серверная часть должна быть запущена — см. [README в корне проекта](../README.md).
