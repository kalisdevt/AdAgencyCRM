# Агентство — клиентская часть

Клиентское приложение CRM рекламного агентства. Сейчас в проекте есть адаптивный экран входа; серверная авторизация еще не подключена.

## Технологии

- Vue 3 с Composition API
- Vite
- JavaScript

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки:

```sh
npm run build
npm run preview
```

Подробные требования и границы MVP находятся в `../docs/Техническое_задание_ред_2.0.docx`.
